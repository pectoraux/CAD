# Frozen Baseline

The architecture baseline is frozen at v1.1 before implementation begins. Implementation must proceed through `docs/work-orders/WORK-001.md` onward.

## Authority

The active authority is the frozen v1.1 specification under `spec/` plus the frozen architecture governance files under `docs/`. The git history preserves the superseded v1.0 pre-implementation freeze.

## Rule

Do not edit frozen specification documents during ordinary implementation work. Any required change creates an Architecture Change Request and a new architecture version before implementation continues.
